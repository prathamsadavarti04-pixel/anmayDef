Video

Footage, and how to get it

Video is stored with Git LFS. In this checkout only pointer files are present, so the clips below are catalogued and named but not yet viewable in the browser. Run git lfs install && git lfs pull to bring the bytes down, then re-open this page.

Why the names say “pending-review” Images were described from their pixels. Videos could not be opened here, so their filenames are derived from folder, date and neighbouring frames, and carry a pending-review marker. After fetching LFS objects, watch each clip and drop the marker while adding the real description — the catalogue already records the LFS oid so nothing is lost.
