Technology

Built from the mechanism up.

Actuators, drive train, control electronics and computer vision — designed as one system rather than assembled from parts.

STRIKE Gen 1 · five independent units

The loop

Four stages, one operator.

01 Detect

Computer vision

Frame-by-frame detection finds aerial objects against sky, terrain and clutter, with confidence scoring for each candidate.

02 Track

Continuous state

Each target is carried across frames with position, heading and velocity, so the operator sees motion rather than snapshots.

03 Prioritise

Threat logic

Proximity, trajectory and approach rate rank candidates, separating routine activity from an actual approach.

04 Respond

Cue and actuate

The turret slews to the selected track and the trigger units are armed, individually or as a group, on operator command.

Software

An operator view, not a data dump.

The tracker runs a live camera feed with a stabilised grid, an overlay for each detected drone and a telemetry strip for track state and gimbal attitude. It is deliberately plain: what is in the air, how sure the system is, and where the turret is pointed.

InferenceOn-platform edge processing for low-latency detection

Mechanism

The parts that have to be right.

Five rifles, five independent actuators — the basis of the five-point trigger array.

Independently actuated, centrally controlled.

Each unit has its own servo-driven trigger and its own control channel. That allows a single shot from one unit, a synchronised burst across all five, or any pattern in between — a decision made at the console, not at the hardware.

The same architecture accepts a camera module, ranging and mission-specific payloads on the same frame.
