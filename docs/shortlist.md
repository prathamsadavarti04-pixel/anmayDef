# Image shortlist

The 64 frames currently used on the site, grouped by what they show, with the page they
were chosen for. Full metadata for all 231 assets is in `assets-catalog.csv`; this file
is the human shortlist.

`hero` = strong enough to lead a section · `good` = supporting · `reference` = documentary value.

To use one of these outside the site, take the file from the `assets/` folder named at the
end of each line (or the web version of the same name in `assets/web/`).
